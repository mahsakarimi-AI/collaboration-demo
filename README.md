# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## New Feature

This feature demonstrates how contributors can propose, review, and discuss new changes through GitHub pull requests.

## How to contribute
1. Open an issue describing the change you want to make.
2. Create a new branch for your changes.
3. Make your changes and commit them with a clear message.
4. Push your branch to GitHub.
5. Submit a pull request for review.
